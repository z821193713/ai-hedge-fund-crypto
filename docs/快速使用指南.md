# AI Hedge Fund Crypto 快速使用指南

## 🚀 快速开始

### 第一步：环境准备
```bash
# 1. 克隆项目
git clone https://github.com/51bitquant/ai-hedge-fund-crypto.git
cd ai-hedge-fund-crypto

# 2. 创建虚拟环境
uv venv --python 3.12
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate.bat  # Windows

# 3. 安装依赖
uv pip sync pyproject.toml
```

### 第二步：配置API密钥
```bash
# 复制环境变量文件
cp .env.example .env

# 编辑.env文件，添加以下密钥：
```

```env
# 必需：Binance API密钥（用于获取市场数据）
BINANCE_API_KEY=your_binance_api_key
BINANCE_API_SECRET=your_binance_secret

# 可选：LLM API密钥（选择一个即可）
OPENAI_API_KEY=your_openai_key        # 推荐：GPT-4
GROQ_API_KEY=your_groq_key           # 快速：Llama模型
ANTHROPIC_API_KEY=your_anthropic_key  # Claude模型
```

### 第三步：配置交易参数
```bash
# 复制配置文件
cp config.example.yaml config.yaml
```

编辑 `config.yaml`：
```yaml
# 基础设置
mode: backtest              # backtest(回测) 或 live(实时)
start_date: 2025-01-01      # 回测开始日期
end_date: 2025-02-01        # 回测结束日期
initial_cash: 100000        # 初始资金

# 交易配置
signals:
  intervals: ["1h", "4h"]           # 分析时间框架
  tickers: ["BTCUSDT", "ETHUSDT"]   # 交易对
  strategies: ['MacdStrategy']       # 使用的策略

# AI模型配置
model:
  name: "gpt-4o-mini"      # 模型名称
  provider: "openai"       # 提供商
```

### 第四步：运行系统
```bash
# 回测模式
export SDKROOT=$(xcrun --show-sdk-path) 
export CPPFLAGS="-I$(xcrun --show-sdk-path)/usr/include/c++/v1" 
export CXXFLAGS="-I$(xcrun --show-sdk-path)/usr/include/c++/v1" 
uv pip install --force-reinstall --no-cache-dir greenlet
uv run backtest.py

# 实时模式（修改config.yaml中mode为live后）
uv run main.py
```

## 🛠️ 自定义策略

### 创建新策略
1. 在 `src/strategies/` 目录创建新文件：

```python
# src/strategies/my_strategy.py
from typing import Dict, Any
import pandas as pd
from src.graph import AgentState, BaseNode

class MyStrategy(BaseNode):
    def __call__(self, state: AgentState) -> Dict[str, Any]:
        data = state.get("data", {})
        # 实现你的策略逻辑
        return {"messages": [...], "data": data}
```

2. 注册策略到 `src/strategies/__init__.py`：
```python
from .my_strategy import MyStrategy
__all__ = ["MacdStrategy", "RSIStrategy", "MyStrategy"]
```

3. 在配置文件中使用：
```yaml
signals:
  strategies: ['MyStrategy']
```

## 🔧 故障排除

### 常见问题

1. **API连接失败**
   - 检查网络连接
   - 验证API密钥是否正确
   - 确认API权限设置

2. **依赖安装失败**
   ```bash
   # 尝试更新uv
   curl -fsSL https://install.lunarvim.org/uv.sh | sh
   
   # 或使用pip安装
   pip install -r requirements.txt
   ```

3. **策略运行错误**
   - 检查配置文件格式
   - 确认策略名称拼写正确
   - 查看错误日志

4. **数据获取失败**
   - 检查Binance API状态
   - 验证交易对名称
   - 确认时间范围设置

## 📈 性能优化

### 提高运行速度
1. 使用更快的LLM提供商（如Groq）
2. 减少分析的时间框架数量
3. 启用数据缓存
4. 使用更少的交易对

### 提高策略质量
1. 使用多个时间框架
2. 组合多种策略
3. 调整策略权重
4. 定期回测验证
